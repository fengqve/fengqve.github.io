# FengQve · Apps for everyday tasks

Independent apps I build and maintain for everyday tasks.

[开发者官网 / Developer website](https://woshichaojidashuaige.com/)

## VeloCopy

**Mac** · 把一批文件拷走，也把复制过程看清楚。选择来源和目标后，查看复制进度，按需暂停和恢复，并等待 SHA-256 校验完成。

[产品说明与支持](https://github.com/fengqve/velocopy-support) · [App Store](https://apps.apple.com/app/id6814212633)

## 赖赖番茄钟 / LaiLai Pomodoro

**Mac** · 在 Mac 上安排专注和休息。计时、休息提醒与会议保护，帮助工作时保留休息的节奏。

[产品说明与支持](https://github.com/fengqve/lailai-support) · [App Store](https://apps.apple.com/app/id6800860151)

## WhiteSail / 白帆

**iPhone** · 查看当前网络反应、波动与中断，在常用位置保存读数，再比较哪里连接更稳定。用于观察连接表现，不承诺修复网络，也不是 Mbps 带宽测速。

[产品说明与支持](https://github.com/fengqve/whitesail-support) · [App Store](https://apps.apple.com/app/id6793896916)

## BlinkPaste / 秒贴

**iPhone** · 把常用回复、地址、签名或提示词保存成片段，切换到秒贴键盘后点选插入，少翻一次备忘录。

[产品说明与支持](https://github.com/fengqve/blinkpaste-privacy) · [App Store](https://apps.apple.com/app/id6783308653)

## 比比怪 / Compy

**iPhone · 中国平台** · 从截图识别商品、外卖、酒店或机票页面的信息，再去支持的中国平台继续查询。减少重复输入；规格、房型、行程、优惠条件与最终价格仍需在目标平台核对。

[产品说明与支持](https://github.com/fengqve/compy-privacy) · [App Store](https://apps.apple.com/cn/app/id6757590970)

## Footfall Tally / 客流计

**iPhone** · 站在候选铺位或场所入口，按实际观察手动计数。每轮默认 15 分钟，保存轮次，再比较同一地点不同时段的记录。

[产品说明与支持](https://github.com/fengqve/flowcount-support) · [App Store](https://apps.apple.com/app/id6791618324)

## Monthmark / 望舒

**iPhone** · 记录周期与相关感受，回顾已记录日期里的变化。用于整理记录，不提供诊断、治疗或用药剂量建议。

[产品说明与支持](https://github.com/fengqve/monthmark-support) · [App Store](https://apps.apple.com/app/id6795900784)
